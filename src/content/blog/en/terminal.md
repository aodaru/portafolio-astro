The command line was the first GUI used in computing. In all these years of interacting with computers I have been lucky enough to experiment with many platforms.

Like every computing enthusiast, I was very drawn to the GNU/Linux command line; the ability to give so much information with text alone is wonderful even today. Comparing it with Windows, MS-DOS back then could not do all that much. (To be clear, there were many similar things, but the way it was applied on Linux was much friendlier, to me in particular). Because of that, even though most of the time I have used Windows, I have always looked for the chance to use the Linux terminal.

Microsoft has worked hard to change this. With the arrival of PowerShell the terminal in Windows got a facelift. We can now say it has many features similar to the ones we find on Linux, even terminal frameworks.

For a while now I have been configuring and testing different features we can use on Windows.

The arrival of package managers has been the most significant change. There are options such as:

- **Winget** — for general application installation.
- **Chocolatey** — it has its own particular charm.
- **Scoop** — for development libraries and utilities.

I am a user of all 3 alternatives, but I prefer Winget and Scoop.

**VIM** or **NeoVim** is another tool I have been able to use on Windows. So much so that I have set aside Windows text editors as such.

There are modules like `z` to get quick access to my favorite locations. There is also `fzf`, which made file search on Linux so much easier.

The Windows terminal itself has been improving. But right now, for the sake of a minimalist design, I am using **WezTerm**.

I will keep testing and experimenting and who knows, maybe I will leave you a small tutorial with my terminal configurations.
