Intranet system built for the company's internal management, automating key processes such as billing, inventory control, employee directory and sales reports.

## Main features

- **Billing by code** — Fast billing system with product code search
- **Employee directory** — Staff data management with profiles and permissions
- **Sales reports** — Dashboard with real-time metrics and data export
- **Materials creation** — Module for adding and editing products with images and prices
- **Quote printing** — Custom template generation for quotations

## Tech stack

- **PHP** — Backend logic and database connection
- **MySQL** — Relational data storage
- **JavaScript** — Frontend interactivity and form validation
- **HTML5 + CSS3** — Responsive user interface
