The goal of this project is to keep a record of the jobs where I have done some kind of development, as well as to share the experiences from these projects and other lessons and challenges I have faced along this learning journey in web development and other tools.

## Stacks

- **Laravel** — PHP development framework.
- **Angular** — Modern web development platform.
- **Bootstrap** — Makes building responsive websites easier.
- **MomentJS** — Parses, validates, manipulates and displays dates with custom formats in JavaScript.
- **Front-Matter** — Adds metadata capabilities to Markdown documents (title, description, etc.).
- **ngx-markdown** — Angular library for rendering Markdown.
